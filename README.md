# Mistrz Jednej Struny od Wujka Szpona

Interaktywny konspekt utworów do zagrania na jednej strunie. Dane są pobierane z pliku KONSPEKT - MISTRZ JEDNEJ STRUNY.xlsx, a okładki znajdują się w katalogu okladki.

Strona: https://wujekszpon.github.io/mistrz-jednej-struny/

## Najczęściej aktualizowane pliki

- KONSPEKT - MISTRZ JEDNEJ STRUNY.xlsx - baza utworów i linków,
- okladki/ - okładki przypisane do pozycji w arkuszu,
- index.html - kod konspektu.
